# M2: Linux desktop, CLI and Keep import

Status: built and tested without a real window, and **not closed**. One exit
criterion is met. The other is the maintainer's to confirm. The work is in
[draft PR #11](https://github.com/sameerkrmishra/jotter/pull/11), which sits on
PR #10 ([M1](m1.md)), with CI green and no human review. The figures below were
measured on 2026-11-02 at commit `b2d3e46` unless stated.

## What was delivered

- **`interop:keep-import`**: Google Keep Takeout import that keeps note times, and
  skips what is already there.
- **`interop:markdown-export`**: one Markdown file per note, with YAML front-matter.
- **`app:cli`**: `jotter` with `add`, `list`, `show`, `search`, `tags`, `import` and
  `export`, on the same database as the desktop app.
- **`app:shared-ui`**: note grid, editor, autosave, tags, search, archive and trash
  views, and a Markdown preview with tappable tasks.
- **`app:desktop`**: one window around `app:shared-ui`, and a window that gives the
  reason if the notes cannot be opened.

## Demo

You need the prerequisites in [CONTRIBUTING.md](../../CONTRIBUTING.md). `JOTTER_DB`
keeps the notes out of your real database, and `XDG_CACHE_HOME` keeps the CLI's class
data archive out of `~/.cache/jotter`.

```sh
./gradlew :app:cli:installDist
scratch=$(mktemp -d)
export JOTTER_DB="$scratch/notes.db" XDG_CACHE_HOME="$scratch/cache"
jotter=app/cli/build/install/jotter/bin/jotter

mkdir "$scratch/Keep"
cat > "$scratch/Keep/shopping.json" <<'EOF'
{
  "title": "Shopping",
  "listContent": [
    {"text": "milk", "isChecked": true},
    {"text": "bread", "isChecked": false}
  ],
  "labels": [{"name": "Home"}],
  "isPinned": true,
  "createdTimestampUsec": 1600000000000000,
  "userEditedTimestampUsec": 1600000500000000
}
EOF
cat > "$scratch/Keep/old-idea.json" <<'EOF'
{
  "title": "Old idea",
  "textContent": "An **archived** note.",
  "isArchived": true,
  "createdTimestampUsec": 1500000000000000,
  "userEditedTimestampUsec": 1500000000000000
}
EOF

$jotter import "$scratch/Keep"   # imported 2
$jotter import "$scratch/Keep"   # imported 0, skipped 2
$jotter list                     # Shopping, pinned, updated 2020-09-13T12:35:00Z
$jotter list --archived          # Old idea, updated 2017-07-14T02:40:00Z
$jotter add --tag Home "Added from the CLI"
$jotter export "$scratch/out"    # exported 3
cat "$scratch/out/Shopping.md"   # front-matter, then - [x] milk and - [ ] bread
```

The desktop app comes last, from the same shell, so that it gets the same `JOTTER_DB`.
**This step was not run for this note**, and nobody has looked at what it shows. The
build was checked; the start was not.

```sh
./gradlew :app:desktop:createDistributable
app/desktop/build/compose/binaries/main/app/jotter/bin/jotter
```

If it works, the window shows the pinned Shopping note and the note from the CLI, and
Old idea in the Archive view. Opening Shopping and pressing Preview should show two
task boxes.

Remove the scratch directory with `rm -r "$scratch"`.

## Decisions made

- [ADR-0009](../adr/0009-import-preserves-source-timestamps.md): imported notes keep
  their source times as revision stamps, an exception to
  [ADR-0003](../adr/0003-revision-dag-and-three-way-merge.md). Only the note id is
  deterministic, and a note with any history is skipped.
- [ADR-0010](../adr/0010-compose-ui-outside-linuxx64-rule.md): `app:shared-ui` builds
  for `jvm` and Android only, an exemption from
  [ADR-0006](../adr/0006-native-compatible-shared-modules.md).
- [ADR-0006](../adr/0006-native-compatible-shared-modules.md): the JVM CLI stays,
  because it meets the threshold. No native CLI and no new ADR.
- Without an ADR, in the module READMEs: the coverage gate uses Kover's JaCoCo engine
  on a JVM-only variant ([build-logic](../../build-logic/README.md)), the CLI ships its
  own start script with a class data archive
  ([`app:cli`](../../app/cli/README.md)), and the editor autosaves 5 s after typing
  stops and at the latest every 60 s, with no Markdown link or image touching the
  network ([`app:shared-ui`](../../app/shared-ui/README.md)).

## Known limitations and what was not verified

What has not been verified:

- **The desktop app in a window.** It was last seen starting in a window before the
  review fixes, and its window contents were never inspected. All later UI checks are
  headless, with `runComposeUiTest`.
- **The failed-open window and `Main.kt`.** These paths have not run in a real window.
  `Main.kt` is excluded from the coverage gate, so no test covers it either.
- **HiDPI and IME.** Both are open from
  [spike 0002](../spikes/0002-desktop-packaging.md) and untested. So is whether the
  spike's one hang after closing the window still happens. `exitProcess` is meant to
  end it, and has not been seen doing so.
- **"Used daily on Linux" and the maintainer's real Takeout.** These are the
  maintainer's to confirm. No real Takeout has been imported.
- **Android.** Device tests were not run. `app:shared-ui` compiles and lints for
  Android, and has run no tests there.
- **Packaging and a CI smoke launch.** Neither is done. CI runs `check` only, and does
  not build the desktop binaries that [PLAN.md §8](../PLAN.md#8-quality-bar) asks for.
- **Timings.** They come from one workstation, and the Markdown parsing times in the
  [`app:shared-ui` README](../../app/shared-ui/README.md) were not measured again.

Known limitations:

- A repeated import skips newer Keep edits of a note it already has. Attachments and
  sharees are dropped with a warning.
- `jotter add` reads text that starts with `-` as an option. Use
  `jotter add -- "- [ ] milk"`, or stdin. The CLI has no pin, archive or trash command.
- The window sees the CLI's writes only when it gains focus.
- Grid cards show a note's text as typed. In the preview, tables show as typed, raw HTML
  and images stay plain text, and links do nothing when tapped.
- A crash loses up to 5 s of text after typing stops, and up to a minute of unbroken
  typing.
- The window runs under XWayland, not native Wayland.
